# 機能仕様書：ユーザー属性・計測環境タグと統計・予測

## 1. 概要・目的
ユーザー個人の集中力推移に加えて、「ユーザー種別（大学生、高校生等）」ごとの統計や、「計測環境（テスト終わり、徹夜明け等）」に応じた集中力変動を分析・予測可能にする。
これにより、「GW明けはみんな疲れやすい」「テスト終わりの自分はこの時間帯に集中力が急減する」といった客観的な洞察を提供する。

---

## 2. ユーザー属性（プロファイル）
- **設定タイミング**: 初回ログイン後のプロフィール設定（変更可能）
- **分類項目**:
  - 大学生
  - 大学院生
  - 高校生
  - 社会人
  - その他

---

## 3. 計測環境タグ（コンテキストタグ）
- **設定タイミング**: テスト結果画面にてワンタップで任意選択（入力スキップ可能・摩擦ゼロ）
- **プリセットタグ候補**:
  - `平常`（デフォルト）
  - `テスト・試験後`
  - `徹夜・睡眠不足`
  - `運動後`
  - `食後・満腹`
  - `休日・連休明け`
- **活用方法**:
  - 「テスト後の平均集中力低下度合」の算出
  - 環境別の回復速度・傾向の把握

---

## 4. 統計・可視化・予測機能
- **個人ダッシュボード**:
  - **集中力推移グラフ**: 日次・週次・月次の集中度変化
  - **時間帯別集中マップ**: 朝・昼・夕・夜・深夜の平均集中力スコア（「この時間は意外と集中力が高い」等の発見）
  - **曜日別集中傾向**: 月曜〜日曜の集中力平均
- **全体統計（属性別比較）**:
  - 同属性（例: 大学生全体）の時間帯別・時期別（GW明け、試験期間等）の平均集中力傾向
- **パーソナライズ予測＆アクション提案**:
  - 現在の時刻・曜日・直近の計測データから、「今のあなたの推定集中力」を予測。
  - 「今は集中力が高まるゴールデンタイムです（重い課題推奨）」、「過去の傾向から、この時間は集中力が低下しやすいです（軽い作業推奨）」とアドバイス。
