# 機能仕様書：疲労・集中力測定テスト（短時間テスト）

## 1. 概要・目的
ユーザーが日常的に受検し、現在の客観的な集中力・疲労状態（集中力スコア）を数値化するための認知・作業パフォーマンステスト。
「疲れていると思って休みすぎる」「疲れていないと思って作業が長期化する」乖離を防ぐため、実作業（課題・レポート・プログラミング等）に近い認知負荷を短時間で測定する。

---

## 2. 検討対象のテスト種別
ユーザーの構想に基づくテストバリエーション：
1. **簡易計算テスト（処理速度・ワーキングメモリ）**
   - 1桁〜2桁の四則演算をテンポよく解く。正答数と回答速度を計測。
2. **タイピングテスト（運動機能・集中維持）**
   - 短い文や英単語、数列を正確に入力。タイピング速度（WPM/CPM）とミス率を計測。
3. **短期暗記テスト（短期記憶・注意力）**
   - 瞬間表示される数列・記号・配置を記憶し、直後に再現・回答。
4. **文章読解テスト（言語処理・読解集中力）**
   - 2〜3行の短文を読み、内容に関する簡単な正誤・三者択一問題に答える。

---

## 3. テスト開発・展開方針（段階的スライス）
- **第9回スライス（最小開通）**:
  - *方針*: 受検→採点→ローカル保存→履歴表示のエンドツーエンドの開通を最優先とする。
  - *第9回テスト仕様*: **「簡易計算ミニテスト」**（シンプルな一桁計算5問、または15秒タイムアタック）。素早く受検でき、スコア（0〜100）が正しく計算されてLocalStorageに保存されることを検証。
- **第10回スライス（本格拡張）**:
  - *方針*: 4種総合テスト（短期暗記・計算・タイピング・文章読解：計約1分）を完全実装し、多面的な認知負荷から総合集中力スコアを算出。

---

## 4. 4種総合テストの構成形式（第10回実装）
- **形式**: **「4種総合ミニテスト」**
- **合計所要時間**: **約2分半〜3分**（各パート約35秒〜45秒）
- **シーケンス**:
  1. **短期暗記**（約40秒）：ランダム数字列・記号の瞬間記憶・回答
  2. **計算**（約40秒）：乱数動的生成によるテンポの良い四則演算
  3. **タイピング**（約40秒）：構文合成／AI生成文のタイピング
  4. **文章読解**（約40秒）：短文の論理判定・4択問題
- **メリット**: 多角的（記憶・計算・運動・言語）な認知負荷を一度にチェックでき、集中持続力を高い信頼性で評価可能。

---

## 5. 出題の重複防止と生成AIストック連携
同じ問題の繰り返しによる学習効果（記憶解き）を防ぐため、以下の多層アプローチを採用する。
1. **計算・暗記**: 乱数・アルゴリズムによる動的無限生成（毎回初見）。
2. **タイピング・文章読解**:
   - 初期（第10回）：単語プール×構文テンプレートによるオフライン自動合成。
   - 拡張（第12〜14回）：**Google Gemini API（無料枠）を用いた30分周期の自動問題生成＆ローカルストック**。

## 6. 評価方法・スコア算出ロジック（正答率×所要時間の統合評価）

単なる正誤のカウントではなく、**「正答率（正確性）」** と **「所要時間（処理速度・反応時間）」** を組み合わせた認知パフォーマンス指標（スループットモデル）を採用する。

### 5.1 評価パラメータ
1. **正答率（Accuracy Rate, $A$）**:
   - $\text{正答率} = \frac{\text{正答数}}{\text{総問題数}}$ (0.0 〜 1.0)
   - 正解率が低下するとスコア全体が大きく減衰する（当てずっぽうの早打ちを防止）。
2. **平均所要時間（Average Response Time, $T_{avg}$）**:
   - 1問あたりの回答にかかった平均秒数。
   - テスト種別ごとの基準時間（例: 簡易計算なら1問あたり $T_{target} = 2.0$ 秒）と比較。
3. **時間ばらつき（Standard Deviation, $T_{sd}$）**:
   - 各問の回答時間のばらつき（標準偏差）。疲労が蓄積すると「特定の設問でフリーズする（注意力の中断）」現象が発生しやすいため、集中維持度の指標として活用。

### 5.2 統合スコアリング計算式（案）
- **速度スコア（$S_{speed}$）**:
  $$S_{speed} = \max(0, \min(100, 100 - (T_{avg} - T_{target}) \times 25))$$
- **総合集中力スコア（$Score$）**:
  $$Score = \text{round}(A^2 \times S_{speed})$$
  - ※ 正答率 $A$ を二乗（$A^2$）で掛けることで、いくら回答が速くてもミスが多い（集中が散漫な）場合は大幅に減点され、逆に「速くかつ正確」なときに高得点（75〜100）となる。

### 5.3 状態判定の目安
- **75〜100点（集中力十分）**: 素早く正確（平均2秒以内、正答率80%以上）。難関課題や重いタスク推奨。
- **50〜74点（標準コンディション）**: 正確だが回答にやや時間を要する、または軽微なケアレスミス。通常の課題推奨。
- **50点未満（集中力低下中）**: 回答速度が著しく遅い、またはミスが頻発（フリーズや集中途切れ）。軽い作業への切り替え・休憩推奨。

## 6. テスト受検フローとフィードバック提示（確定）
1. **テスト開始**: 余計な事前入力やネットワーク接続待ちを挟まず、完全オフラインでもワンクリックですぐに「1分〜1分半の4種総合テスト」を開始。
2. **テスト実施**: 暗記（15s）→ 計算（20s）→ タイピング（20s）→ 読解（25s）をテンポよく受検。
3. **結果＆アクション・フィードバック表示**:
   - **現在の実測集中力スコア**（例: `集中力スコア 78 / 100`）
   - **能力別内訳**（暗記・計算・タイピング・読解）
   - **状態判定メッセージ（アクション指示）**:
     - スコア高（75以上）：「⚡ まだまだ集中力十分です！重い課題や難関タスクを一気に進めましょう」
     - スコア中（50〜74）：「☕ 集中力は標準的です。無理のないペースで、通常の課題を進めましょう」
     - スコア低（50未満）：「🛌 集中力が低下しています。時間を浪費する前に、軽い作業に切り替えるか休憩を挟みましょう」
   - **個人傾向比較**: 「いつものこの時間帯（夜）より＋15%高い状態です」などの客観コメント。
4. **オフライン永続化**:
   - ネット未接続時でもブラウザローカル（LocalStorage / IndexedDB）に測定データが即座に保存され、オフラインのまま履歴や統計の確認が可能。
   - オンライン復帰・アカウントログイン時にクラウドへ自動バックアップ／同期される。
